Constructor in java : 

1. Constructor is an special type of method whose name is same as class Name.
2. it looks like an method but does not have return type.
3. when we create an object of class then constructor will get automatically called .
4. there are two types constructor in java 

1> non-parameterised Constructor / NO args Constructor  / default Constructor 
2> Parameterised Constructor / args Constructor

when we cannot declared any constructor in java then system(Compiler) will provide u default constructor.

suppose if we provide return type to the constructor then it will become method
Constructor is used to initialized object.

syntax : 


AccessSpecifier ClassName(){

}


example : 

public class Employee {


public Employee(){

syso("this is Constructor");

   }
}
