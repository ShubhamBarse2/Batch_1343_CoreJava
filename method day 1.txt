MethodName : 

Naming Conventions rules to declared an method : 

1. cannot used keyword as method name 
2. cannot start with numbers (special symbol) 
3. method name should be logical 
4. space not allowed 
5. first start with lowercase then uppercase(myInfo , myStatus...)
