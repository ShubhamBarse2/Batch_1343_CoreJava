Operator in java : 

Operator is an special symbol which used to performed operation on values or operands 

like as --> + , - , * , > , < % , / = etc  


Operator --> special type symbol --> DR    --> +
Operand  --> value / data   -- > patient   --> 3 , 5
operation --> process / task  --> heart operation  --> addition


type of operators base on Operand : 

1.unary (single operand) --> i++
2.binary (two operands)  --> 4+3
3.ternary (three operands) --> 5+6+7


type of operators base on Operation : 

Arithmetic 
Relational / Comparison
